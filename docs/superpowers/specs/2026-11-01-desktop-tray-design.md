# Компьютер на связи с закрытым окном — дизайн

Дата: 2026-11-01. Решение владельца в чате: «Иконка в трее + автозапуск»,
выключается в настройках.

Продолжает `2026-10-12-desktop-calls-design.md` («Что не входит: звонок на
закрытый ПК (пушей на ПК нет)»).

## Зачем

Пушей на компьютер нет: сообщения и звонки приходят, только пока жив процесс
CubeChat и открыт его сокет к релею. Сейчас крестик окна завершает процесс —
и компьютер замолкает до следующего ручного запуска.

## Что

### Windows

- **Крестик прячет окно в трей**, процесс и релей живут. Входящий звонок
  звонит тем же уведомлением Windows с «Відповісти / Відхилити», сообщения —
  тем же баннером, что сейчас.
- **Иконка в трее**: клик — открыть окно; меню — «Відкрити CubeChat» и
  «Вийти». «Вийти» — единственный способ завершить процесс из интерфейса.
- **Ответ на звонок или клик по баннеру** показывает окно и выводит его вперёд.
- **Автозапуск** при входе в Windows, сразу в трей (аргумент `--hidden`),
  без окна. Запись в `HKCU\…\Run` — только для этого пользователя, без прав
  администратора.
- **Выключатель** в Профіль → Сповіщення і дзвінки: «Запускати разом із
  Windows». Включён по умолчанию — решение владельца; выключение снимает запись
  автозапуска. Крестик прячет в трей независимо от выключателя: иначе
  «закрыл — перестал звонить» вернулось бы для всех, кто его выключил.

### Mac

Так, как принято на Mac: закрытие окна **не завершает** приложение, оно
остаётся в Dock и продолжает получать сообщения; клик по иконке в Dock
возвращает окно; завершение — Cmd+Q. Звонков на Mac нет (WebRTC собран только
под Windows), поэтому этого достаточно. Автозапуск на Mac — не в этой версии.

### Телефоны

Не меняются: ни один из новых пакетов не вызывается вне компьютера.

## Пакеты

`window_manager` (перехват закрытия, показать/спрятать), `tray_manager`
(иконка и меню), `launch_at_startup` (запись автозапуска). У всех трёх нет
Android/iOS-части; вызовы закрыты проверкой платформы.

## Юридические документы

Ничего не уходит с устройства. В политике одна строка: CubeChat для Windows по
умолчанию запускается при входе в систему и работает в фоне, пока его не
закрыть через «Вийти»; отключается в настройках.

## Тестирование

- Контроллер (фейковые окно, трей, автозапуск): закрытие прячет, не
  завершает; «Вийти» завершает; выключатель пишет и снимает автозапуск;
  `--hidden` не показывает окно; на телефоне ничего не вызывается.
- Сборка Windows в CI; Mac — локально.

Только вживую: закрыть окно на Windows, позвонить с телефона — звонит;
перезагрузить ПК — CubeChat в трее, звонок проходит.
